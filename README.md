# ChaosSMP 1.1.0

Paper 1.21.11 / Java 21. Includes `/spawn`, `/setspawn`, `/stats`, `/top` and four spawn leaderboards:
kills, deaths, best killstreak and playtime. K/D is intentionally not included.

## Build on GitHub
1. Upload the **contents** of this project to the root of a GitHub repository.
2. Open Actions and run `Build ChaosSMP`.
3. Download artifact `ChaosSMP-1.1.0`.
4. Inside it, use `ChaosSMP-1.1.0.jar` and place it in `plugins/`.
5. Restart the Paper server.

The JAR is shaded with SQLite JDBC. This source archive is not itself a compiled JAR.
